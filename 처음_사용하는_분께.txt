========================================================================
 노후건축물 안전점검 대상 선별 앱 — 처음 사용하는 분께
========================================================================

개발 지식이 없어도 아래 순서대로 하면 내 컴퓨터 브라우저에서 앱을 볼 수 있습니다.
걸리는 시간: 처음 한 번 15분 정도, 다음부터는 더블클릭 1번.


------------------------------------------------------------------------
 1. 압축 풀기
------------------------------------------------------------------------
받은 zip 파일을 더블클릭해 풀고, 풀린 폴더를 바탕화면이나 '문서' 폴더로 옮기세요.
(폴더 안에 '시작하기(Mac).command', '시작하기(Windows).bat' 파일이 보이면 맞습니다)


------------------------------------------------------------------------
 2. 파이썬 설치 (처음 한 번만)
------------------------------------------------------------------------
이 앱은 '파이썬'이라는 프로그램으로 돌아갑니다. 3.11 이상 버전이 필요합니다.

  1) https://www.python.org/downloads/ 접속
  2) 노란색 "Download Python 3.x.x" 버튼 클릭 → 받은 설치 파일 실행
  3) [Windows만] 설치 첫 화면 아래쪽 "Add python.exe to PATH" 를 반드시 체크한 뒤 Install
  4) 설치가 끝나면 창을 닫습니다.

이미 설치했는지 모르겠다면 그냥 3단계로 가세요. 없으면 안내가 나옵니다.


------------------------------------------------------------------------
 3. 처음 실행 — 프로그램 설치와 키 파일 만들기
------------------------------------------------------------------------
[Mac]
  '시작하기(Mac).command' 를 더블클릭합니다.
  "확인되지 않은 개발자" 경고로 열리지 않으면:
    → 파일을 마우스 오른쪽 클릭 → [열기] → 다시 [열기]
    (그래도 안 되면: 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기")

[Windows]
  '시작하기(Windows).bat' 를 더블클릭합니다.
  "Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] → [실행]

검은 창(터미널)이 뜨고 필요한 프로그램을 설치합니다(인터넷 필요, 3~10분).
글자가 한동안 멈춰 있어도 정상이니 기다리세요.

설치가 끝나면 '키 파일(.env)'이 텍스트 편집기(Mac)나 메모장(Windows)으로 열립니다.
→ 4단계로 가세요.


------------------------------------------------------------------------
 4. 키 넣기 (처음 한 번만)
------------------------------------------------------------------------
'키'는 공공 데이터를 받아 오기 위한 비밀번호 같은 값입니다.
열린 .env 파일에서 '=' 바로 뒤에 받은 키를 붙여 넣고 저장하세요(Mac: Cmd+S, Windows: Ctrl+S).

  예)  BUILDING_API_KEY=여기에키붙여넣기      ← 띄어쓰기 없이

꼭 필요한 것부터:
  BUILDING_API_KEY     건축물대장 조회. 이게 없으면 '조회·판정'이 안 됩니다.
  VWORLD_GEOCODER_KEY  지도에 건물 핀 표시
  VWORLD_DATA_KEY      지도에 동 경계 표시
  LLM_PROVIDER 등      공고문 자동 추출. 비워 두면 '샘플 결과'로만 동작합니다(외부로 안 보냄).
  LAW_API_OC           조례 동기화(담당자 PC 전용). 일반 사용자는 비워 두세요.

키는 담당자에게 따로(메신저 대화방에 그대로 올리지 말고) 받거나, 각자 무료로 발급받습니다.
  - 건축물대장: 공공데이터포털(data.go.kr) → "건축HUB 건축물대장정보" 검색 → 활용신청
                → 마이페이지에서 '일반 인증키(Decoding)' 복사
  - 브이월드:   vworld.kr → 인증키 발급(지오코더, 2D 데이터) → 서비스 URL에 http://localhost:8501 입력

.env 파일을 나중에 다시 열고 싶을 때:
  [Mac]     폴더에서 Cmd+Shift+. (점) 을 누르면 숨은 파일이 보입니다 → .env 를 텍스트 편집기로 열기
  [Windows] 폴더에서 .env 파일을 오른쪽 클릭 → 연결 프로그램 → 메모장


------------------------------------------------------------------------
 5. 앱 켜기 (매번)
------------------------------------------------------------------------
'시작하기' 파일을 다시 더블클릭하면 브라우저가 자동으로 열리고 앱이 뜹니다.
  - 주소: http://localhost:8501  (브라우저가 안 열리면 이 주소를 직접 입력)
  - 끝낼 때: 검은 창을 닫으면 됩니다.
  - 이 주소는 내 컴퓨터 안에서만 열립니다. 다른 사람이 접속할 수 없습니다.


------------------------------------------------------------------------
 6. 화면 사용법 (3분)
------------------------------------------------------------------------
위쪽 버튼으로 화면을 바꿉니다.

 ② 지역 일괄 대조  ← 여기서 시작
   1) 왼쪽에서 시·도 → 시·군·구 → 법정동(여러 개 가능)을 고릅니다.
   2) [조회·판정] 클릭 → 건물별로 '1차 후보 / 확인필요 / 조례만 충족 / 비해당'이 나옵니다.
   3) 표에서 건물 한 줄을 누르면 아래에 상세(조건별 비교, 현장확인 항목)가 열립니다.
   4) [Excel 내려받기]로 결과를 저장합니다.
   ※ 결과는 '자격 후보'입니다. 최종 선정은 담당자·위원회가 합니다.

 ③ 안내문 및 결과 리포트
   소유자 안내문 초안을 말투별로 만들고 Word(docx)로 내려받습니다.
   발송 전 반드시 담당자가 검토합니다.

 ④ 지도
   [지도 좌표 가져오기]를 누르면 후보 건물이 지도에 핀으로 표시됩니다.
   핀을 누르면 오른쪽에 건물 상세가 나옵니다.

 ① 공고문 분석 & 조건
   공고 파일(HWP·HWPX·PDF·이미지)을 올려 조건을 뽑고, 원문과 대조해 저장합니다.
   저장한 공고는 왼쪽 '공고' 목록에 나타나고 판정에 쓰입니다.

 시험해 보기 좋은 예: 서울특별시 → 종로구 → 청운동 → [조회·판정] (건물 약 360건)


------------------------------------------------------------------------
 7. 이럴 땐
------------------------------------------------------------------------
 - "BUILDING_API_KEY가 없습니다" → 4단계에서 키를 넣고 저장했는지, 앱을 다시 켰는지 확인
 - "조회하지 못한 동" → 공공데이터포털 서버가 잠깐 바쁜 경우가 많습니다. 1~2분 뒤 다시 [조회·판정]
 - 브라우저에 "사이트에 연결할 수 없음" → 검은 창이 닫혀 있으면 '시작하기'를 다시 더블클릭
 - "Port 8501 is already in use" → 이미 켜져 있습니다. 브라우저에서 http://localhost:8501 을 여세요
 - 설치 중 오류 → 인터넷 연결 확인 후 다시 더블클릭. 계속되면 검은 창 화면을 캡처해 담당자에게 전달
 - 새로고침하면 조회 결과가 사라짐 → 정상입니다(개인정보 보호를 위해 저장하지 않음)


------------------------------------------------------------------------
 주의
------------------------------------------------------------------------
 - .env 파일(키)은 다른 사람에게 보내지 마세요. 폴더를 다시 공유할 때는 .env 와 .venv 폴더를 빼세요.
 - 건축물대장 조회 결과와 지도 좌표는 저장되지 않습니다. 필요한 결과는 Excel로 내려받으세요.
